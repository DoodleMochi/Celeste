# Celeste
Replaces the standard ACNL manual with information on fish, bugs, fossils, and paintings, so you don't have to close your game to look up how much your catch is worth. Does not update dynamically like Blathers, and as such may contain spoilers.

REQUIRES A MODDED 3DS

Information is from the following pages, and used with permission:
https://nookipedia.com/wiki/Sea_creature/New_Leaf
https://nookipedia.com/wiki/Fish/New_Leaf
https://nookipedia.com/wiki/Art/New_Leaf
https://nookipedia.com/wiki/Fossil/New_Leaf

### Structure:
Manuals only support a maximum of 99 separate pages (buttons you click on the main Manual menu). Unfortunately, there are:
- 30 Sea Creatures
- 72 Fish
- 72 Bugs
- 33 (x2) Art
- 57 + 10 Fossils

To help keep things organized within these limitations, I intend to make the manual as follows:
- 13 pages of Fish, one for each month + one for Tortimer Island
- 13 pages of Sea Creatures, one for each month + one for Tortimer Island
- 13 pages of Bugs, one for each month + one for Tortimer Island
- 3 pages of Art, one for Statues and 2 for paintings, split between A-M and N-Z.
- 3 pages of Fossils, one for the 10 standalone fossils and 2 for the multi-part fossils, split between A-M and N-Z

This means a total of 45 pages, which is... a lot, but it's at least less than 99. Recommendations on alternative organization schemes are welcome. Note that each type will be color-coded and grouped together, so it should at least be usable.

### Guaranteed features at final release:
- All listings will include the buy and sell values of each item
#### Bugs, fish, and sea creatures:
- Rarity
- Active times
- Active months
- Location (including if they can be found on Tortimer's Island)
#### Fish and sea creatures:
- Shadow size
#### Sea creatures:
- Movement behavior
#### Art:
- Images of both the real and fake paintings/statues
- Text description of changes between the real and fake paintings/statues
- Price difference between the real and fake paintings/statues
#### Fossils:
- Name of set
- Number of fossils in set

### Possible features depending on technical limitations:
- Images for all items
- Average size for bugs, fish, and sea creatures
- Icons for things like bells, shadow size, etc
- LayeredFS patching (fingers crossed on this one)

If LayeredFS patching is not possible with this mod, a patching tool will be created for use with your own legally acquired ACNL:WA roms. I unfortunately cannot guarantee that Celeste will support the base ACNL like Blathers will.
